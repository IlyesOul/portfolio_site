meta-learning workflow

training across users and few-shot adaptation to a new user. select the image to view it at full size.

learning movie embeddings with SimCLR

the self-supervised embedding pipeline that supplies representations for the recommendation models. select the image to view it at full size.

program description

I designed, implemented, and evaluated multi-step meta-learning regressors from scratch in PyTorch to tackle the complex landscape of film preferences. By leveraging episodic task sampling, the program enables rapid model adaptation to unseen user profiles, even under extreme data scarcity.

the core architecture utilizes a custom SimCLR self-supervised learning pipeline. It uses stochastic feature masking, dropout, and noise augmentations to project unstructured, discrete film metadata attributes into continuous, learned vector representations, testing non-linear ranking quality through an out-of-sample framework.

evaluation

at 20 ratings per unseen user, Reptile reached 0.846 NDCG versus at most 0.832 for the comparison baselines. the project explored rapid adaptation from just 5–20 ratings.
